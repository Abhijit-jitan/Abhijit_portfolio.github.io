Automated Plank & Pipe Count Platform

Industry: Manufacturing & Warehousing     Technology: Computer Vision, Object Detection     Deployment Type: Mobile / Edge / On-Premise

Problem Statement

Counting large stacks of planks or pipes—often consisting of hundreds or thousands of items—is a repetitive, time-consuming, and error-prone task in manufacturing yards and warehouses.

Manual counting leads to inaccurate inventory records, operational delays, and increased labor effort, especially when handling bulk materials.

Objectives

  • Automate counting of plank and pipe stacks using computer vision
  • Eliminate manual counting errors and delays
  • Enable fast counting using a simple mobile application
  • Provide reliable and repeatable count results

Solution Overview & Approach

Solution Overview:
A vision-based counting platform that detects and counts individual planks or pipes from images of stacked materials using a trained object detection model.

Approach:

  • Collected real-world image data of plank and pipe stacks
  • Annotated datasets to label individual planks and pipes
  • Trained a deep learning object detection model for accurate counting
  • Developed a mobile application to capture or upload stack images
  • Detected and counted each plank/pipe to compute the total count

Tech Stack

Computer Vision: Deep learning–based object detection for identifying and counting individual planks and pipes from stacked images.

Backend: Python-based inference service handling model execution, image preprocessing, and count aggregation.

Mobile Application: Lightweight mobile app allowing users to capture images or upload existing photos for instant counting.

Deployment: Edge or on-premise deployment for low-latency inference in warehouse and yard environments.

High-Level Architecture

The system follows a modular pipeline consisting of image capture, preprocessing, object detection, count aggregation, and result visualization.
