Automated Fabric Shrinkage Detection App

Industry: Textile & Apparel Manufacturing     Technology: Computer Vision, Image Processing     Deployment Type: On-Premise / Edge

Problem Statement

In the textile and garment manufacturing industry, fabric shrinkage and expansion during processing stages (washing, dyeing, finishing) leads to dimensional inconsistencies between raw and processed fabric.

Traditional shrinkage measurement relies heavily on manual measurement techniques, which are time-consuming, error-prone, and not scalable for high-throughput production environments.

Objectives

  • Automate fabric shrinkage and expansion measurement using computer vision
  • Ensure consistent dimensional quality across raw and processed fabric
  • Reduce human error and manual intervention
  • Provide measurable shrinkage percentage for quality control teams

Solution Overview & Approach

Solution Overview:
An automated vision-based inspection system that measures dimensional changes between raw and processed fabric using predefined reference markings.

Approach:

  • Apply predefined reference markings on raw fabric samples (e.g., 50×50 cm or 35×35 cm)
  • Capture high-resolution images of raw fabric before processing
  • Capture images of the same fabric after processing
  • Detect and measure distances between markings using computer vision
  • Compare raw vs processed measurements to calculate shrinkage or expansion percentage

Tech Stack

Computer Vision: OpenCV-based image processing for marker detection, contour analysis, and distance measurement.

Backend: Python-based processing pipeline for measurement logic, calibration, and comparison algorithms.

UI / Application: Lightweight desktop or web-based interface to upload images and visualize shrinkage results.

Deployment: On-premise or edge-device deployment for factory-floor usage without cloud dependency.
