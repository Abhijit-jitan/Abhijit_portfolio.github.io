Automated Fabric Shrinkage Detection App

Industry: Textile     Technology: Computer Vision     Deployment Type: On-Premise

Problem Statement

In textile manufacturing industry, fabric shrinkage and expansion during processing stages (washing, dyeing, ironing) leads to dimensional changes between raw & processed fabric.

Traditional shrinkage measurement relies heavily on manual measurement techniques, which are time-consuming, error-prone, and not scalable for high-throughput production environments.

Objectives

  • Automate fabric shrinkage and expansion measurement using computer vision
  • Reduce human error and manual intervention
  • Provide measurable shrinkage percentage for quality control teams
  • Governance Dashboard for application monitoring
  • Match fabric barcode with warehouse & POCC data
  • Automated Calibration App
  • User-friendly Operators application for Shrinkage Detection App

Solution Overview & Approach

Solution Overview:
Automated vision-based inspection system that measures dimensional changes between raw and processed fabric using predefined reference markings.

Approach:

  • Apply predefined reference markings on raw fabric samples (e.g., 50×50 cm or 35×35 cm)
  • Controlled Camera env to capture high-resolution images of processed fabric
  • Detect & measure distances between markings using computer vision
  • Compare raw vs processed measurements to calculate shrinkage or expansion percentage
  • Match the Barcode on fabric and push the shrinkage percentage to POCC
  • Governance Dashboard
  • Automated Calibration App

Tech Stack

AI: OpenCV-python, Numpy, Detection

Backend: FastAPI

UI / Application: User-friendly Pyqt5 desktop operator's application & React based Governance application

Deployment: On-premise GPU Server
