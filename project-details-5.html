Realtime Automated Towel Count System

Industry: Textile     Technology: Computer Vision     Deployment Type: On-Premise & GPU Server

Problem Statement

In textile manufacturing units, towel rolls are produced continuously on high-speed machines. Accurately counting towels manually is time-consuming, error-prone, and inefficient, especially under high production loads.

Traditional mechanical count/manual count lack accuracy at speed and do not integrate well with modern digital production systems.

Objectives

  • Automate Yash textile machine with modbus relay & Raspberry pi(reliable stop/start control from a centralized system)
  • Camera & Light connection setup
  • Towel data collection, model train & model evaluation
  • Optimized towel inference pipeline for towel detection & counting
  • Ensure accurate counting without slowing production
  • Connect Raspberry-pi to central gpu server for direct access
  • Operator's app to input towel batch details to count, monitor & control the machine

Solution Overview & Approach

Solution Overview:
Real-time, vision-based towel counting system tightly integrated with textile machinery, lighting, industrial cameras, GPU inference, and machine control using Raspberry Pi and Modbus relays.

Approach:

  • Hardware like Camera, Light, Gpu server installation & connection
  • Modbus rellay & Raspberry-pi connection with textile rolling machine to control start & stop
  • Streamed camera frames to a GPU server for real-time inference
  • Connected a Raspberry Pi to the GPU server via optical fiber
  • Towel data collection, model train & evaluation
  • Pyside operator's application to input roll details, controll machine on/off & monitor the towel count

Tech Stack

Computer Vision: Detection, Yolo, Pytorch

Hardware Integration: MVS camera, flood lighting, Modbus relay, Raspberry Pi

Backend & Control: Flask based gpu inference pipeline, detection/count logic, control signaling for start/stop conditions

Deployment: On-premise GPU server, Raspberry-pi
