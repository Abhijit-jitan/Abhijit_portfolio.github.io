GenAI Led Multidomain Query Platform

Industry: Mining & Enterprise     Technology: GenAI     Deployment Type: Azure

Problem Statement

Large enterprises accumulate massive volumes of unstructured documents across diverse domains such as Subsurface, WCR, HR Policy, Public Policy, MIS Reports, and Procurement.

Traditional search systems fail to ensure domain isolation, contextual accuracy, and secure access, resulting in incorrect answers, cross-domain data leakage, and poor research efficiency.

Objectives

  • Enable accurate domain-specific querying across 12,000+ heterogeneous documents
  • Ensure strict RBAC-based access control for each business domain
  • Support automated ingestion & scheduled ingestion of multiple enterprise document formats
  • Provide GenAI-powered synthesis and research assistance
  • Response latency less than ~10 seconds
  • Proper citaion/reference
  • User friendly UI & usage
  • Governance Dashboard
  • 400-500 concurrent users & over 19000+ users support
  • Feedback loop

Solution Overview & Approach

Solution Overview:
Azure deployed GenAI platform with Nextjs & Fastapi(be) which will do knowlwdge mining with over ~15K unstructured/atructured documents,hybrid document search with RAG to get, proper response ,Synthesis new draft,Research assistance ,Strict isolation & access control,scheduled AD sync,scheduled automated Doc ingestion

Approach:

  • Scheduled multi-format ingestion pipeline for XLS/XLSB, DOC/DOCX, PDF, TXT, RST, MSG, DB
  • Domain-wise embeddings & documents metadata inside Azure MongoDB Vcore vector-db
  • Semantic chunking , filters, metadata during ingestion
  • RBAC-driven query routing in FE to prevent cross-domain leakage
  • GenAI-powered synthesis for contextual answers & research insights
  • RAG based model to fetch response by filtering the metadata & hybrid embedding search
  • Proper reference document/citations fetch with document preivew stack
  • Display platform usage, model configuration, cost analytics, error monitoring inside governance Page
  • Lightweight, Responsive, Enterprise grade interface built using Nextjs for secure and feedback driven enterprise querying

Tech Stack

AI: claude sonet, gpt4.1, RAG model, langchain & langchain graph, Hybrid search, data connectors,

FE: Nextjs, chartsjs & RBAC Access control

Backend: FastAPI with RBAC rules, Ingestion pipelines, Azure CosmosDB NoSQL, Azure MongoDB, JWT Token based session managed Id.

Deployment: Azure Devops, Docker, Azure container App/job, Enterprise grade CI/CD pipelines.
